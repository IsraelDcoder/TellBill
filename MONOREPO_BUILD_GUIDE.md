# TellBill Monorepo - Build & Deployment Guide

## 📁 Directory Structure

```
/TellBill
├── /mobile/                    ← Expo React Native App (runs EAS builds from here)
│   ├── package.json           (mobile dependencies only)
│   ├── app.json               (Expo configuration)
│   ├── eas.json               (EAS Build profiles - preview APK, production AAB)
│   ├── App.tsx
│   ├── screens/, components/, navigation/, etc.
│   └── android/               (native code, generated by expo prebuild)
│
├── /server/                   ← Express.js Backend API
│   ├── index.ts
│   ├── routes.ts
│   └── (services, middleware, utils, etc.)
│
├── /shared/                   ← Shared types and utilities
│
├── package.json              (backend dependencies only)
├── tsconfig.json             (backend Node.js config)
├── render.yaml               (Render deployment config)
├── Dockerfile                (Docker build for backend)
└── (other root files)
```

## 🚀 Build & Deployment Commands

### **Mobile App (Expo React Native)**

All mobile commands run from `/mobile` directory:

```bash
# Navigate to mobile directory
cd mobile

# Development
npm start              # Start Expo dev server
npm run android        # Run on Android device/emulator
npm run ios            # Run on iOS device/simulator

# Building for Testing (APK)
eas build --platform android --profile preview --no-wait

# Building for Production (AAB for Play Store)
eas build --platform android --profile production --no-wait

# Monitor build status
eas build --list
```

**⚠️ Important**: Always run EAS commands from `/mobile` directory, NOT from root!

---

### **Backend API (Express.js)**

All backend commands run from root `/TellBill` directory:

```bash
# Development
npm run dev            # Start with tsx (hot reload)

# Production
npm run build          # Compile TypeScript → server_dist/index.js
npm start              # Run compiled server

# Database
npm run db:push        # Sync schema to database
npm run db:reset       # Reset database (dev only)
npm run db:backup      # Create database backup

# Docker
npm run docker:build   # Build Docker image
npm run docker:up      # Start Docker containers
npm run docker:down    # Stop Docker containers
```

## 🌍 Deployment

### **Backend - Render.com**

The backend automatically deploys when you push to `main` branch.

**Render Build Process:**
1. ✅ Clones repository
2. ✅ Runs: `npm ci --include=dev`  (install all deps including dev tools)
3. ✅ Runs: `npm run build`          (compiles TypeScript with esbuild)
4. ✅ Generates: `server_dist/index.js`
5. ✅ Runs: `npm start`              (starts compiled server on port 3000)

**View logs:**
- Go to [Render Dashboard](https://dashboard.render.com)
- Click on "tellbill-backend" service
- View "Logs" tab

---

### **Mobile - EAS Build (Expo)**

Build Android APK or AAB for Play Store:

```bash
cd mobile
eas build --platform android --profile preview  # APK for testing
eas build --platform android --profile production  # AAB for Play Store
```

**View builds:**
- Dashboard: https://expo.dev/accounts/therealme/projects/tellbill/builds

## ✅ Checklist Before Deployment

**Before Backend Deploy:**
- [ ] `npm run build` succeeds locally
- [ ] No TypeScript errors: `npx tsc --noEmit`
- [ ] Changes committed and pushed to `main`

**Before Mobile Build:**
- [ ] `npm install` succeeds in `/mobile`
- [ ] `npx expo prebuild --clean` generates `android/` folder
- [ ] `npm start` works locally for testing
- [ ] Changes committed and pushed to `main`

## 🔧 Troubleshooting

### Backend won't start
```bash
npm run build          # Ensure it compiles
npm start              # Check for runtime errors
NODE_ENV=production npm start  # Test production mode
```

### Mobile app won't build
```bash
cd mobile
rm -rf node_modules package-lock.json
npm install --legacy-peer-deps
npx expo prebuild --clean
```

### EAS says "Cannot find module"
- Ensure you're in `/mobile` directory
- Ensure you removed any root `eas.json` (only `/mobile/eas.json` should exist)
- Verify `app.json` exists in `/mobile`

✅ **Backend** can build & deploy independently  
✅ **Mobile** has clean Expo + React Native dependencies  
✅ **Shared** code available to both  
✅ **No conflicts** between dependency versions  
✅ **Faster builds** (smaller, focused package.json files)  

---

## 📝 Important Notes

- `root /package.json` = Backend ONLY dependencies
- `root /eas.json` = Should NOT exist (causes errors)
- `/mobile/package.json` = Mobile ONLY dependencies  
- `/mobile/eas.json` = Mobile build configuration
- Always check **which directory** you're in before running commands!
